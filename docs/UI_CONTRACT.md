# Контракт активного GUI

Активні вкладки: Експеримент; Сигнал і канал; Декодування; Результати та ефективність; Дослідження.

Порівнюємо лише два повні приймачі: роздільний B0 / Хемінг та спільний Joint / Евклід. Різниця результатів є системним контрастом, а не ізольованим ефектом метрики.

B1, ізольовані A-H/A-E та інші експерименти не мають активних GUI-маршрутів. Історичні дані, backend і математичні алгоритми зберігаються.

Верхня панель містить назву, п’ять вкладок, статус і єдиний навігатор елементів, відліків, інформаційних та кодових бітів. Для системного кадру індекси переводяться за 8 відліків, 2 інформаційні та 3 кодові біти на елемент.

Без описів під заголовками, службових панелей та внутрішніх ID. Сумісні DOM-вузли старих обробників тримаються від’єднаними від документа, без дублювання ID в активному DOM.

Підтримувана платформа: desktop 1366–2560 px, повна ширина сторінки. Модельну енергетичну шкалу не називаємо фізичним Eb/N0. Наукове ядро та історичні результати не змінюємо.

# Матеріали COPYRIGHT-DOCS-01 для незалежного перегляду

Цей комплект містить два підготовлені DOCX, звіт перевірки, п’ять актуальних скриншотів Scientific Workspace, перелік програмних файлів із SHA-256 та копії цих вихідних файлів для незалежного звірення.

## Основні документи

- `Опис_компютерної_програми_HF-TCM-SIM.docx` — призначення програми, компоненти, алгоритм роботи, п’ять рисунків і незаповнений реквізит авторства. Word визначив 5 сторінок.
- `Текст_програми_HF-TCM-SIM.docx` — повний надрукований текст 27 файлів HF-TCM-SIM: 7 599 рядків; Word визначив 142 сторінки. Жоден включений файл не скорочувався.
- `docs/copyright/COPYRIGHT_DOCS_01_VERIFICATION.md` — підсумок відповідності зразкам, перевірок і обмежень.

## Зміст архіву

- `source_snapshot/` — точні копії включених вихідних модулів із шляхами репозиторію.
- `screenshots/` — п’ять оригінальних PNG, вбудованих у документ опису.
- `reports/` — реєстр джерельних файлів і скриншотів, незалежна перевірка, аналіз шаблону, звіт та інструменти для відтворення/перевірки документів.
- `previews/` — PDF-копії для візуального перегляду, якщо Word-експорт завершився.
- `AUDIT_MANIFEST.json` — розмір і SHA-256 кожного іншого файла ZIP; сам маніфест не може включати власний хеш.

## Наукові обмеження та незаповнені дані

Програму описано як офлайновий академічний симулятор. Модельні дискретні енергетичні показники не названо фізичним Eb/N0, а виграш 1,5 дБ зі статті не приписано цій реалізації. ПІБ автора/авторів комп’ютерної програми не підтверджено за матеріалами репозиторію; поле в описі потребує заповнення перед поданням.

## Перевірка

Незалежний перевіряльник порівнює всі надруковані програмні рядки з оригіналами, перевіряє SHA-256 файлів, вміст і пропорції скриншотів, а також CRC пакетів DOCX. Архів має власний SHA-256, а CRC і всі записи маніфесту повторно перевіряються під час пакування.

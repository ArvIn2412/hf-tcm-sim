# M11j — Звіт про мінімалістичний UX Simulation Studio

**Статус: `MINIMALIST_UX_READY`**

## Реалізований інтерфейс

Demo Studio відкривається сторінкою **Моделювання**. Параметри згруповані за інформаційною послідовністю, кодером, каналом/детермінованим noise fixture, приймачем та аналізом. Головна навігація містить шість розділів: Моделювання, Етапи сигналу, Відліки сигналу, Приховані стани, Декодування та Результати. На кожній сторінці доступні пояснення, довідка та кнопки переходу вперед/назад. Розширені таблиці, trace details, exports та архівні дані залишилися доступними.

Етапи сигналу містять десять вибірних блоків, які показують фактичний trace: інформаційні біти, вихід кодера, переходи TCM, символи 8PSK, переданий комплексний baseband, rectangular ZOH, застосоване підсилення, шумові відліки, прийняті комплексні відліки та observed I/Q. Hidden-state траєкторії каналу позначені як недоступні, оскільки активна демонстрація їх не обчислює. Передавач і приймач описані як модельні комплексно-огинаючі входи/виходи, а не як RF hardware, passband conversion або активна HF multipath модель.

Сторінка відліків розділяє огляд кадру, рухоме вікно на 20 символів/160 відліків та деталізацію на 20 відліків. Індекси відліків абсолютні; вибір символу синхронізує TCM і Viterbi сегменти. Для коротких кадрів показуються лише фактичні відліки без padding. Інтерфейс прямо зазначає, що вікно 20 символів є візуальною навігацією, а декодер працює за наявним full-frame conditional Viterbi алгоритмом.

Подання прихованих станів розділяє решітку TCM та приховані параметри каналу. Декодування має вкладки метрик, оцінювача та Viterbi. Результати розділяють поточну демонстрацію та read-only архів M5–M10; одиничний trace позначається як демонстрація, а не статистичний доказ. Зміна параметра після запуску зберігає попередній результат і позначає його `STALE`. Навігація не запускає приймач. Новий trace створюється лише після явної дії «Запустити симуляцію».

Проєкторне подання підтримує великий графік, згортання sidebar, тему, нотатки доповідача, fullscreen та параметри. Перевірені viewport: 1366×768 і 1920×1080.

## Наукові обмеження

Збережено `paper_exact:false`, `receiver_enabled:false`, SCI-02/SCI-03/SCI-METRIC-02 OPEN. Encoder B залишається source-derived preview без встановленого phase mapping і сумісного receiver. Demo trace та архівний dashboard не додають performance evidence. Production mathematics, ADRs та M5–M10 artifacts не змінювалися; Monte Carlo не запускався. M12 не починався.

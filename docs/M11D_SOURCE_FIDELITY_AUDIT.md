## Exact-source interpretation

The article supports a rate-2/3, 8PSK coding context, the displayed recurrence structure [A](1), the quadrature predictor family [A](5), a trellis illustration, and the phase increment Δφ=π/4. Those matches do not make the integrated project receiver paper-exact. The equation images for [A](1), [A](2), [A](5), the phase definition and Fig.3 were visually inspected in addition to document text extraction. In particular, [A](2) visibly does not print the square that production applies to its residual.

`SOURCE_AUDIT_COMPLETE`: the source pages/equations, project assumptions, implementation paths, test coverage and GUI claims have been reviewed and recorded. `PAPER_PARTIAL`: a limited set of structures is source-supported, while material conventions and metric semantics remain reconstructed or unresolved. No production mathematics or historical result was changed during this audit.

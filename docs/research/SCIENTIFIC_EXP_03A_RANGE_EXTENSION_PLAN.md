# SCIENTIFIC-EXP-03A — зафіксований pilot range extension

**Статус:** цей план зафіксований до запуску додаткових розвідувальних кадрів. Це не confirmatory серія; результати не входять до SCIENTIFIC-EXP-03B.

## Мета

Уточнити межі лише там, де первинна п'ятиточкова сітка не локалізувала ціль BER=0,05 або перетин лежав на краю. Усі нові записи мають окремі experiment IDs і seed domains; первинні пілотні каталоги не перезаписуються.

## Незмінні параметри

- Кадр: 128 елементів сигналу; по 5 незалежних парних кадрів на енергетичну точку.
- AWGN sample-domain variance: 0,05; sweep масштабує амплітуду, а не шум.
- Статичний канал: taps `1+0j` та `0.3−0.2j`, затримки `[0,3]`.
- Rician AR(1): середні потужності `[1,0.25]`, K `[4,1]`, LOS-фази `[0,0.7]` рад, затримки `[0,3]`, `ρ=0.98` на відлік.
- Пілотна схема: 4 preamble; блок 4 кожні 32 елементи; `η=20`; A-E/A-H мають спільний frontend і observation.
- Seed roots: AWGN direct `831041`; AWGN pilot `831042`; static `831043`; Rician `831044`.
- Перезапуск дозволений тільки з незмінною конфігурацією та відновлює manifest/checkpoint.
- Максимальний бюджет: 120 s на серію; записи після кожного кадру.
- Усі підсумки позначаються `range_finding`; цілі та тренди мають лише діагностичне призначення.

## Додаткові сітки

| ID | Режим | Відступи від базового `A=1` |
|---|---|---|
| `exp03a-range2-awgn-direct-v1` | AWGN без пілотів/equalizer | `[-18,-16.5,-15] dB` |
| `exp03a-range2-awgn-pilot-v1` | AWGN зі спільним pilot frontend | `[-12,-10.5,-9,-7.5] dB` |
| `exp03a-range2-static-d3-v1` | Static `[0,3]` зі спільним pilot frontend | `[-13.5,-12,-10.5,-9] dB` |
| `exp03a-range2-rician-ar1-v1` | Rician AR(1) зі спільним pilot frontend | `[-3,0,3,6,9] dB` |
| `exp03a-range2-rician-pilot8-v1` | Rician AR(1), pilot burst 4 кожні 8 елементів | `[-3,0,3,6,9] dB` |

Плановий обсяг: `110` парних кадрів, плюс 100 первинних pilot frames; це все ще лише розвідувальні спостереження. Період 8 для Rician додається як окремий tracking/overhead sensitivity arm, оскільки період 32 виявив великий вік оцінки за `ρ=0.98` на відлік. Після перегляду нових даних сітку SCIENTIFIC-EXP-03B слід зафіксувати окремим незмінним протоколом до створення будь-яких confirmatory records. Не переносити пілотні кадри до основної серії.

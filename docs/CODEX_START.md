# Запуск у Codex після готового M0

**Не проси Codex створювати M0:** він уже реалізований у цьому пакеті.

1. Відкрий кореневу папку `hf-tcm-sim` у Codex (не зовнішню папку з ZIP).
2. Запусти команди setup/smoke із `README.md`.
3. Передай **один** промпт із `NEXT_TASK.md`.
4. Приймай M1 тільки після тестів і перевірки SCI-02.
5. Далі окремі промпти для M2, M3, M4, M5 відповідно до `PLAN.md`.

Для економії токенів: не вставляй повне ТЗ у чат Codex; у репозиторії
є всі матеріали. Читай тільки ті параграфи ТЗ, що стосуються поточної задачі.

# GUI_UX-01 — звіт про доопрацювання інтерфейсу

Статус: **GUI_UX_01_PARTIAL**. Архівний пакет сформовано й перевірено; приймання GUI не охопило всі обов'язкові канальні сценарії та обидві роздільності повністю.

## Зміни інтерфейсу

- Прибрано з видимого інтерфейсу прапорець точності, коди етапів, службовий футер, run ID та observation hash. Метадані продовжують зберігатися у backend результатах.
- Параметри згруповано у три колонки на широкому екрані з адаптивним переходом до двох/однієї; додаткові коефіцієнти променів доступні у згортаній секції.
- Верхня навігація зведена до символу, відліку й приймача. Старі дубльовані елементи приховані, їхні DOM bindings залишені для сумісності інтерфейсного коду.
- Підписи приймачів, метрик, станів, переходів і таблиць локалізовані. Показано визначення параметрів через кнопки `?` із підтримкою миші, клавіатури й дотику.
- Сузір'я малюється у квадратному canvas 360×360 з фіксованим радіусом. Кодер подано таблицею символів, бітових пар, трійок, станів і фаз.
- Для решітки додано легенду, фільтр переходів, колір локального survivor path і окремий колір поточного переходу.
- Графік бітових помилок показує дискретні значення 0/1 та нульову лінію; нуль помилок є валідним результатом.

## Науковий аудит

Детальна звірка першоджерел наведена у [GUI_UX_01_ARTICLE_COMPLIANCE_AUDIT.md](GUI_UX_01_ARTICLE_COMPLIANCE_AUDIT.md). Первинне джерело v7 підтверджує кодерну схему `c₂=u₀`, `c₁=u₁ XOR D²u₁`, `c₀=Du₁`, чотири стани та 16 переходів. Евклідова метрика у приймачі, Rician AR(1), дискретна шумова конвенція та частина індексації залишаються проєктними реконструкціями. Прапорець `paper_exact:false` у наукових метаданих незмінний. Energy gain 1,5 dB не підтверджено.

## Перевірки

- Edge при 1366×768: п'ять перевірок пройшли: компактні три колонки й приховані технічні прапорці, три глобальні поля, клавіатурно-керована підказка, реальний Identity запуск із нульовим BER обох приймачів на тому самому observation, квадратне 360×360 сузір'я. Зняті скриншоти дев'яти вкладок.
- 1920×1080: валідного скриншота у цій сесії немає; невдала CDP capture спроба не зарахована.
- Поточний запуск Edge не повторив Static Multipath, Rician і Monte Carlo сценарії. Їхні збережені REPRO-10A результати залишені як попередні backend evidence, не як нове GUI приймання.

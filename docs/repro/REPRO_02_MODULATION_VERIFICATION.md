# REPRO-02 — mapping і 8PSK перевірки

## Профіль маркування

`adr002_assumed_natural_binary_c2_c1_c0_v1` інтерпретує output triple `(c2,c1,c0)` як натуральний binary phase index `b=4c2+2c1+c0`. Це явна реконструкція ADR-002, не підтверджене авторське маркування всіх гілок. Таблиця містить усі 16 ребер зі стабільним edge ID та фазовим індексом; fingerprint таблиці: `c1d30e713ca13a448456f6aa4597bcd34ba9087795d93c4db8095987e3c8102b`.

## Комплексна модуляція

Використано `S[k]=A exp(j(φ₀+b[k]Δφ))`, `Δφ=π/4`. `A` і `φ₀` — явні config-параметри. Приклади задають `A=1`, `φ₀=0` як project profile, а не як джерельно визначені значення. Знак уявної частини відповідає `exp(+jφ)`; додаткове спряження або поворот не вноситься.

Unit tests перевіряють усі вісім фаз, кругову відстань π/4, енергію `A²`, комплексний знак і повторюваність. Комплексні символи зберігаються як complex128, а `symbol_i`, `symbol_q`, `phase_values_rad`, `symbol_energies` — як float64.

## ZOH

Для кожного символу формується рівно вісім однакових комплексних відліків. Absolute sample index, symbol index і local sample index `[0..7]` є явними масивами. Перевірено перший/середній/останній символ, межі блоків, довжину та відсутність off-by-one.

Фільтрація імпульсів, RF carrier, канал, шум та приймачі до цього етапу не належать.

# REPRO-06C: адаптивний оцінювач променів

Новий ізольований модуль `hf_tcm.repro.survivor_channel_estimator` містить окрему оцінку комплексних коефіцієнтів для кожного survivor augmented trellis node. Для поточного інтервалу прийняті значення оцінювача не використовуються під час прогнозу кандидатів; вимірювання впливають лише на фільтр переможної гіпотези після вибору predecessor для destination node.

Для регресора `x` і коефіцієнтів `h` модель спостереження — `y = xᵀh + w`. Комплексний Kalman записує `z = conj(x)`, отже `y = zᴴh + w`. Прогноз: `h⁻ = m + ρ(h−m)`, `P⁻ = ρ²P + Q` для AR(1); для unknown-static `h⁻=h`, `P⁻=P/λ`. Інновація `e=y−zᴴh⁻`, `S=R+zᴴP⁻z`, `K=P⁻z/S`, `h⁺=h⁻+Ke`, `P⁺=P⁻−KzᴴP⁻`. Коваріація симетризується ермітово; від'ємні власні значення поза допуском спричиняють помилку, а малі числові значення обмежуються заданим covariance floor.

Для REPRO-03 Rician AR(1) початкове середнє є публічним LOS середнім `sqrt(P K/(K+1)) exp(jφ)`, стаціонарна дисперсія diffuse складової `P/(K+1)`, а `Q=(1−ρ²)P/(K+1)`. Оновлення виконується на кожному sample. Це оцінювальна проєктна модель, а не твердження про точну фізичну HF-модель.

Незалежні scalar fixtures у `tests/repro/test_survivor_channel_estimator.py` перевіряють ручний комплексний update зі спряженням, один крок AR(1), вироджений регресор, delayed ZOH design для D=3 та незалежність пам'яті двох survivor updates. Початкові mean/covariance, `ρ`, `λ`, measurement noise та regularization є обов'язковою частиною серіалізованої конфігурації; автоматичного підбору за reference bits немає.

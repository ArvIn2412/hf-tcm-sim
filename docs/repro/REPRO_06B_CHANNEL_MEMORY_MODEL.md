# REPRO-06B — модель пам'яті каналу

## Контракт

REPRO-06B розглядає комплексну огинаючу з REPRO-02/03:

\[
y[n]=\sum_{\ell=0}^{L-1}h_\ell[n]x[n-d_\ell]+w[n],
\]

де `n` і `d_l` — цілі абсолютні індекси відліків, `x`, `h`, `w`, `y` — комплексні величини. Передавач повторює символ ZOH протягом 8 відліків; межі кадру використовують zero-extension. REPRO-06B не створює RF carrier, fractional-delay filter, stochastic channel чи нові SNR значення.

Для каналу з максимумом затримки `D` відліків мінімальна історія фазових символів дорівнює `q = ceil(D/8)`. Розширений вузол має вигляд `(encoder_state, previous_phase_history[q])`. Encoder A має чотири базові стани та чотири вихідні переходи з кожного стану. Фаза попереднього символу не визначається одним станом Encoder A, тому її необхідно зберігати окремо.

Поточна реалізація підтримує `q <= 2`, тобто `D <= 16` цілих відліків. Більші затримки відхиляються під час перевірки конфігурації. Загальна верхня межа числа вузлів — `4 * 8^q`, ребер — не більше чотирьох на вузол; фактичний граф будується як reachable BFS-граф з початкового стану, тому зазвичай менший. Глобальні запобіжники: 256 вузлів і 2048 ребер.

## Відліки та хвіст

Для переходу `k` основне вікно — абсолютні відліки `[8k, 8k+8)`. Останні `D` відліків REPRO-03 мають індекси `[8F, 8F+D)` і належать останньому transition score. Вони містять лише відкладений внесок переданого кадру; не утворюють нового TCM-символу. За `D=3` кадр `F=20 000` має 160 000 переданих і 160 003 прийнятих відліки, а tail індекси 160000–160002 оцінюються разом із переходом 19999.

Нульове початкове продовження визначає відсутні відліки до кадру. Післякадрове продовження також нульове згідно з REPRO-03. Усі відліки оцінюються рівно один раз; жодне обрізання не виконується.

## Обчислювальна складність

Для `F` символів, `S` reachable expanded nodes, `E` expanded edges і `8+D` відліків на перехід, прогноз/метрики мають порядок `O(F E (8+D) L)` у прямому визначенні. Статичний профіль повторно використовує передобчислені phase/history templates; Viterbi має `O(F E)` час. Full-frame diagnostic arrays мають розмір `O(FS)`. Finite-depth core зберігає не більше `eta` predecessor rows, тобто `O(eta*S)` survivor storage, плюс необхідні `O(F)` вихідні рішення та, якщо викликано batch API, `O(FE)` branch rows.

Інші затримки перевірено: `D=0` дає 4 вузли/16 ребер; `D=3` — 17/68; `D=9` та `D=16` — по 69/276 reachable вузлів/ребер у поточному графі. Це розміри реалізованих графів для Encoder A і природного двійкового фазового mapping, а не загальна формула для всіх trellis.

Статус профілю: `[ПРОЄКТ]` memory-aware модель для статично відомих коефіцієнтів. Вона не доводить source-exact HF channel fidelity.

# Інструкції Codex — HF-TCM-SIM

Мета: відтворювана **офлайнова академічна симуляція** згорткового коду R=2/3,
8PSK, модельних каналів і декодування Вітербі. Без SDR, реального радіозв'язку
або керування БПЛА.

1. Спочатку читай `PLAN.md` та `NEXT_TASK.md`. З повного ТЗ читай **лише розділи,
   потрібні поточному етапу**; не перечитуй усі великі документи без потреби.
2. Працюй **тільки над поточною фазою**, не впроваджуй наступні автоматично.
3. Відрізняй `[СТАТТЯ]`, `[ПРОЄКТ]`, `[УТОЧНИТИ]` у доках і коді.
   Не вигадуй фазове маркування як авторське, параметри завмирань чи
   адаптивну евклідову метрику; див. `docs/ASSUMPTIONS_AND_DECISIONS.md`.
4. Немає незалежного доказу 1,5 дБ; не підганяй результати й не приписуй
   їх власному коду.
5. Код — Python >=3.11, пакет `src/hf_tcm`, мінімальні зміни, типізація,
   детермінований RNG у майбутніх симуляціях, тести для нової поведінки.
6. Перед завершенням: `python -m pytest -q`, `ruff check .`,
   `ruff format --check .` (якщо доступно). Зазначай **фактично** запущені команди.
7. Не роби git commit/push, не встановлюй додаткові сервіси без запиту.
   Онови `PLAN.md` тільки після справжньої перевірки. Зупинись після фази.

Детальні вимоги: `docs/TECHNICAL_SPECIFICATION.md`;
наукові прогалини SCI-01…08: `docs/ASSUMPTIONS_AND_DECISIONS.md`.

# Контрольний список приймання конференційних матеріалів

- [ ] Основна стаття 2026 року прочитана; короткі тези RTF розглянуто як допоміжне джерело.
- [ ] Створено **три** основні редаговані файли: PPTX, текст DOCX, Q&A DOCX.
- [ ] У презентації **немає** кібербезпекових текстів, імені Горбача та чужих результатів.
- [ ] Назва доповіді і реквізити доповідача підтверджені джерелом або позначені плейсхолдерами.
- [ ] На слайдах показано **проблему**, **мету**, **відомий тракт**, **удосконалення технології**, **імітаційний результат**, **висновки**.
- [ ] Схема КР → Д → БОВ → БТО → ДВ з оригіналу видима й читабельна.
- [ ] Описано адаптацію геометрії 8PSK в рамках м'якого декодування Вітербі.
- [ ] Математичні формули (якщо вставлені) візуально тотожні оригіналу та читаються.
- [ ] Результат 1,5 дБ атрибутовано статті; відсутня неправдива заява про точне відтворення.
- [ ] Немає вигаданих BER-кривих, BER targets, вибірок, фізичного Eb/N0 чи статистичних інтервалів статті.
- [ ] Презентація не перевантажена: орієнтовно 8–9 основних слайдів.
- [ ] Доповідь **5–7 хвилин**, текст погоджений зі speaker notes усіх слайдів.
- [ ] Q&A містить складні запитання про 1,5 дБ, відмінності умов моделювання й межі застосовності.
- [ ] Усі файли відкрито в редакторі / перевірено структурно, DOCX рендерено по сторінках, PPTX по слайдах.
- [ ] Для ілюстрацій зазначено джерела.
- [ ] Фінальний ZIP у корені `hf-tcm-sim` містить три готові файли, SOURCE_CROSSWALK, QA_REPORT, README_FOR_CHATGPT, SHA-256 manifest.

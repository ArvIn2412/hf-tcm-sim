# HF-TCM-SIM — пакет для Codex: конференція 12.11.2026

У цьому ZIP зібрано надані користувачем зразки трьох матеріалів, тези Яковіва–Гриненка та докладне завдання для GPT-6.1 Sol / Codex.

## Як використати

1. Скопіюй `HF_TCM_CONFERENCE_2026_11_12_CODEX_INPUT.zip` у корінь `hf-tcm-sim`.
2. У Codex надішли одне повідомлення:
   
   > У корені проєкту лежить `HF_TCM_CONFERENCE_2026_11_12_CODEX_INPUT.zip`. Розпакуй його у папку `conference_2026_11_12_input/` без зміни файлів. Прочитай `conference_2026_11_12_input/CODEX_PROMPT.md`, `SOURCE_MAP.md` і всі приклади, а також основну статтю Яковіва–Гриненка в `references/`. Повністю виконай завдання: створи три готові файли презентації, тексту виступу й питань-відповідей для доповіді 12.11.2026 (5–7 хв); використовуй оригінальні рисунки й формули наукових джерел; перевір рендеринг; створи `HF_TCM_CONFERENCE_2026_11_12_FINAL.zip` у корені проєкту.

3. Після завершення завантаж три файли або фінальний ZIP в ChatGPT для незалежної перевірки.

## Що міститься в пакеті

- `CODEX_PROMPT.md` — повне технічне завдання.
- `SOURCE_MAP.md` — як використовувати джерела, особливо твердження про 1,5 дБ.
- `CHECKLIST.md` — контроль кінцевого результату.
- `examples/` — три зразки іншої тематики, **тільки для структури та стилю**.
- `sources/` — надані тези Яковіва–Гриненка (RTF), PDF-прев'ю та точні вирізки рис. 1 і формул (1), (2) для зручного вставлення.
- `MANIFEST_SHA256.json` — реєстр контрольних сум (сам маніфест не включено до самоконтрольованого переліку).

## Наукова примітка

Число **1,5 дБ** у тезах — результат, **заявлений у статті/тезах**. Не називати його відтвореним у HF-TCM-SIM. Відтворені в інших дослідженнях моделі 5,780 і 2,456 дБ характеризують інші умови й не є підтвердженням 1,5 дБ.

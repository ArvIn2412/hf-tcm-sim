# Конфігурації

`m0_smoke.json` перевіряє **тільки CLI/парсинг**. Він навмисно не задає
Eb/N0, Rician K, labeling, кількості шляхів чи інших наукових параметрів.
Реальні сценарії з'являться у M1–M5 після погодження контрактів.
Питання SCI-01…08 див. `docs/ASSUMPTIONS_AND_DECISIONS.md`.

`docs/RECONSTRUCTED_OFFLINE_CONFIG.md` описує окрему strict schema для
профілю `reconstructed_offline`. Це поки не preset експерименту: профіль не
активує receiver, не задає наукових defaults і не є paper-exact. За явним
рішенням користувача від 2026-10-26 як проєктні припущення прийняті тільки
ADR-002, ADR-006, ADR-007, ADR-008 та ADR-010; ADR-003/004/005/009/011 лишаються
proposed. Жодне з цих рішень не підтверджує модель статті [A].

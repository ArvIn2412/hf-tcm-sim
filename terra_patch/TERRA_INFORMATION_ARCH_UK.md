# HF-TCM-SIM — інформаційна архітектура Terra Focus

## П'ять верхньорівневих задач

| Назва для користувача | Початкова вкладка | Призначення |
|---|---|---|
| Моделювання | `parameters` | Профіль, параметри наступного запуску, запуск |
| Сигнал | `transmitter` / `constellation` | TX/RX і сузір'я на одному навігаційному рівні |
| Декодування | `viterbi` | Рішення та шлях Вітербі |
| Результати | `metric` | Порівняння метрик і статистика |
| Історія | `saved` | Каталог досліджень |

Для розділу «Сигнал» передбачено вторинне перемикання «Передавач і канал» / «Сузір'я 8PSK», зі збереженням останнього вибору.

## Обмеження поточного пакета

Це **UX-шар поверх шести фактичних вкладок**, а не фізичне об'єднання усіх внутрішніх контейнерів. Це дозволяє не чіпати обробники роботи з науковими даними та уникнути порушення вже перевіреного коду. Реальне спільне полотно TX/RX + 8PSK вимагає доступу до останнього локального стану frontend/API та функціональних E2E-тестів.

## Інтеракції

- Первинні кнопки викликають існуючі `button[data-view]`, отже механізм відкриття реального view залишається авторитетним.
- `aria-current=page` синхронізовано з оригінальною активною вкладкою через `MutationObserver`.
- Основний навігатор стислий, але повна функціональність доступна через «Інструменти».
- Провенанс джерела згорнутий, але доступний через «Джерело даних · Деталі».
- Якщо DOM несумісний і потрібних вкладок немає, скрипт не активує новий режим.

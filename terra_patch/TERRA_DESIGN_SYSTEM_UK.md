# Terra Focus — мінімальна дизайн-система

## Стиль

- Тло `#f8fafb`, поверхня `#ffffff`.
- Основний текст `#172532`, другорядний `#607280`.
- Акцент `#096d72`, делікатне акцентне тло `#e3f2f0`.
- Лінії `#dbe4e8`, радіус контейнерів 10px.
- Без важких тіней, неонового декору й великих бейджів.
- Чіткі focus-visible стани, `prefers-reduced-motion`.

## Ієрархія

Головна навігація (5) → контекстне підменю (сигнал) → заголовок робочої задачі → основний графік або форма → інструменти за потреби → деталі джерела.

## Важливий науковий принцип

Візуальна палітра навігації не перепризначає кольори чи математичні значення на графіках. Порівнювані H/E криві не перемальовуються з інших даних. Наявні графічні рендерери зберігаються без змін.

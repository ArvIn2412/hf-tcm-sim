# HF-TCM-SIM — Terra Focus (перший інтеграційний UX-шар)

**Статус:** готовий для локального випробування, **не пройшов браузерне приймання на останній локальній версії Codex**. Це не заявка на `UX REDESIGN: COMPLETE`.

## Що змінюється

- Основна навігація: **Моделювання · Сигнал · Декодування · Результати · Історія**.
- У розділі **Сигнал** залишаються два доступні підрозділи: **Передавач і канал** та **Сузір'я 8PSK**.
- Використовуються старі `button[data-view]` та їхні оригінальні обробники подій: зміна маршрутизації не зачіпає симуляцію.
- Спільний навігатор за замовчуванням компактний, додаткові інструменти відкриваються кнопкою.
- Технічне джерело даних доступне через «Джерело даних · Деталі».
- Прибрано зайві тіні, зменшено рамки та щільність декоративних елементів, додано читабельну адаптивну типографіку.
- На мобільних розмірах навігація використовує горизонтальне прокручування всередині панелі, без необхідності прокручувати всю сторінку.

**Не зроблено:** фактичне об'єднання TX/RX і 8PSK в одному одночасно видимому графічному полотні; оптимізація всіх графіків; повне дослідження браузерних сценаріїв. Це потребує актуального локального репозиторію та браузерного запуску.

## Встановлення у Windows PowerShell

Скопіюй три файли до кореня `hf-tcm-sim`:

- `terra_focus.css`
- `terra_focus.js`
- `install_terra_focus.py`

Потім у корені репозиторію:

```powershell
python .\install_terra_focus.py
python .\install_terra_focus.py --apply
python -m hf_tcm.repro.scientific_studio --port 8765
```

Відкрий `http://127.0.0.1:8765/scientific`. Якщо сервер уже відкритий, перезапусти його й виконай `Ctrl+F5` у браузері. Якщо актуальна версія має іншу HTML-структуру, інсталятор зупиниться без змін.

### Скасувати UI-шар

```powershell
python .\install_terra_focus.py --undo
```

Ця команда прибере два підключення з `scientific.html` і не змінить інші файли. Оригінальна копія HTML зберігається поруч як `scientific.html.terra-before`.

## Перевірки після встановлення

1. П'ять головних розділів, два підрозділи «Сигналу».
2. Всі кнопки переходів і ті самі дані активного дослідження.
3. Показ/приховування інструментів навігатора й джерела даних.
4. Перехід до символу 19 999 і відліку 159 999 (якщо відповідний результат відкритий).
5. Ширини 320, 390, 834, 1366, 1920 px — без JS exceptions та document overflow.
6. Zoom/pan/LOD, сузір'я, дві метрики Вітербі, BER, архіви — без функціональної регресії.
7. `python -m pytest -q -m "not historical"` і source-scoped Ruff з актуального релізного документа.

**Безпечність:** Python-модулі декодерів, експериментальні протоколи та результати SCIENTIFIC-EXP-03B цей пакет не змінює. Не створює commit і не виконує push.
